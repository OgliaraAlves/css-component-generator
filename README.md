# CSS Component Generator

Interactive project developed to generate visual components and animations with real-time preview.

## Overview

This project was created to practice DOM manipulation, interactivity and dynamic interface building using HTML, CSS and JavaScript.

The proposal is to allow the user to type a simple description and instantly preview the generated visual result.

## Features

- Text input for component description
- Ready-to-use example buttons
- Dynamic component generation
- Generated code display
- Real-time preview
- Copy code button
- User feedback interactions
- Responsive interface

## Technologies

- HTML5
- CSS3
- JavaScript

## Technical highlights

- DOM manipulation
- Click events
- Dynamic content rendering
- Real-time UI updates
- Responsive layout
- Interactive user experience

## How to run

1. Download the project files
2. Open `index.html` in your browser
